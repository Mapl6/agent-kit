# ADR-003: `project.json` is generated, deterministic and committable

Status: Accepted · 2026-10-03

## Decision

The project model lives in `.agent-kit/project.json`. It is fully generated by
`agent-kit init` / `index` and carries a `$comment` saying so. It contains no
timestamps and no absolute paths. `index` rewrites it only when its serialized
content changes. `scan --model` prints the same JSON without writing.

## Reason

- Spec §9 calls for a machine-readable model as the central source of truth.
  Later phases (adapters, context engine, verification) read it rather than
  re-deriving facts.
- Determinism means re-running `index` on an unchanged repo produces no diff,
  so the file can be committed and reviewed.
- Spec §52 separates generated files from user-owned ones. Developer input
  (decisions, rules, overrides) will live in separate user-owned files and take
  precedence over this one (spec §53). It will never be hand-edited into
  `project.json`.

## Consequences

- Volatile data (timestamps, hashes, absolute root) stays in `snapshot.json`, the local cache.
- Changing the shape of the model bumps `schemaVersion`.

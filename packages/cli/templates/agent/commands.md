# Commands

Exact commands — agents should use these verbatim instead of guessing.

| Task | Command |
|---|---|
| Install dependencies | `{{INSTALL_CMD}}` |
| Run dev server | `{{DEV_CMD}}` |
| Run all tests | `{{TEST_CMD}}` |
| Run one test file | `{{TEST_CMD}} -- path/to/file.test.ts` |
| Lint | `{{LINT_CMD}}` |
| Format | `[e.g. npm run format]` |
| Typecheck | `[e.g. npm run typecheck]` |
| Build | `{{BUILD_CMD}}` |
| E2E | `[e.g. npm run test:e2e]` |
| Storybook | `[e.g. npm run storybook]` |
| Deploy to staging | `[command]` |
| Deploy to production | `[command — human approval required]` |

# Skill authoring

Skills are short playbooks under `/agent/skills/<name>/SKILL.md`.

## Hardlines

- One skill = one job
- Keep Procedure numbered and verifiable
- Prefer linking existing rules/docs over duplicating them
- Do not put secrets or environment-specific tokens in skills

## When to add a skill

Use `/agent/skills/skill-authoring/SKILL.md` after a repeated workflow shows up in `session-log.md`.

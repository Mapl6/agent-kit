# USER.md

Curated **user preferences** for agents in this repo (optional). Soft budget ~1375 characters.
Separate entries with a line containing only `---`.

Examples: communication style, timezone, "prefer diffs over full rewrites", review strictness.
Do not store secrets. For personal-only voice, prefer gitignored root `SOUL.md` (see `SOUL.md.example`).

```

---
Timezone: [e.g. UTC+3:30]
---
Ask before large refactors or dependency upgrades
```
